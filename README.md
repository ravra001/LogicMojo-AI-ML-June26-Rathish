## Course Syllabus

### Module 1: Basic to Advanced Python
- Python Deep-Dive: Number types, strings, formatting, built-in functions, collections (Lists, Tuples, Dictionaries), exception handling, and regular expressions.
- Data Analysis and Visualization Stack:
  - NumPy: Vector stacking, broadcasting, shape manipulation, and statistics.
  - Pandas: DataFrames, indexing, sub-setting, filtering, and statistical data analysis.
  - Matplotlib and Seaborn: Controlling line properties, subplots, visualising statistical/linear relationships, and categorical plotting.

### Module 2: Applied Statistics in Machine Learning
- Foundations and Distributions: Populations, samples, measures of dispersion, Gaussian/Standard Normal distribution, Z-Scores, PDF, and CDF.
- Statistical Thinking: Central Limit Theorem, Covariance, Pearson/Spearman coefficients, Q-Q plots, Skewness, Log-normal, Box-Cox transformations, and Poisson distributions.
- Advanced Inference: Strict emphasis on Hypothesis Testing and multi-sector forecasts.

### Module 3: Machine Learning and Core Frameworks
- Supervised Learning (Regression and Classification): Linear, Logistic, Ridge, Lasso, Support Vector Machines (SVC), Decision Trees, Naive Bayes, and Random Forest.
- Unsupervised Learning and Clustering: K-Means, Hierarchical Clustering, Mean-Shift, Principal Component Analysis (PCA), Independent Component Analysis (ICA), and FP-Growth association rules.
- Recommendation Systems: Collaborative filtering, matrix completion tasks, and co-occurrence matrices.
- Advanced Paradigms: Reinforcement Learning (Deep Q-Learning via OpenAI), and Ensemble Methods (Boosting, Gradient Boosting, XGBoost).

### Module 4: Deep Learning, NLP and Computer Vision
- Deep Learning Frameworks: Core architectures utilizing TensorFlow, Keras, and PyTorch.
- Deep Learning Algorithms: Artificial Neural Networks (ANN), Recurrent Neural Networks (RNN), Convolutional Neural Networks (CNN), Autoencoders, and Boltzmann Machines.
- Natural Language Processing (NLP): Tokenization, Bag of Words, Word Vectorizers, LSTMs, Neural Machine Translation, Transformers, BERT, and XLNet.
- Computer Vision: Image manipulation via OpenCV, Haar Cascade Classifiers, pedestrian detection, and face recognition.

   source logicmojo_env/bin/activate

2. Install Core Frameworks:
   pip install numpy pandas matplotlib seaborn scikit-learn tensorflow torch opencv-python nltk langchain
